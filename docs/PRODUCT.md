# Relay 产品规格

状态：Codex 主对话、真实项目、文字资料及缓存相关诊断已接入；后续能力按下文目标推进。需求更新：2026-09-22。

## 1. 产品定位

Relay 是一个面向本地 AI Agents 的桌面统一入口，让 Codex、Claude Code、OpenCode 等 Agent 可以在电脑上的任何场景被即时调用。用户可以使用 Relay 托管的版本，也可以连接已有安装。

**项目持续保存上下文，主 Agent 负责协调工作，具体 Agent 通过 ACP 接入执行。**

用户在网页、文档或桌面操作中唤起 Relay，把当前材料加入项目，并在 Relay 内与项目主 Agent 沟通。主 Agent 根据目标决定直接回答、继续已有线程或拆分任务交给其他 Agent。

“本地”描述 Agent 的运行位置；模型推理是否联网取决于所选 Agent 的配置。

## 2. 已明确的决策

| 项目 | 决策 |
| --- | --- |
| 名称 | Relay |
| 形态 | 桌面 Agent Client，提供随处唤起入口 |
| 用户对话对象 | Relay 客户端中的 Agent，默认是项目主 Agent |

| 平台优先级 | macOS 优先 |

首发以 macOS 为主，当前开发构建最低 macOS 15，UI 框架为 GPUI + GPUI Kit；对外发布日期尚未确定。选型依据见 [UI 框架选型](UI-FRAMEWORK.md)。

## 3. 项目是长期工作的容器

| 项目内容 | 作用 |
| --- | --- |
| 目标与指令 | 描述要完成的工作、约束和工作习惯 |
| 主对话 | 用户与主 Agent 沟通目标、补充信息、调整方向 |
| 执行线程 | 查看具体任务的进度、负责 Agent、消息与产物 |
| 资料库 | 保存网页摘录、文件、截图、转写与相关引用 |
| 共享记忆与决策 | 累积可复用事实、已确定方案及其来源 |
| 成果 | 保存各线程生成的文档、代码、分析与其他产物 |

项目可以是研发、研究、写作或日常工作主题，不要求绑定代码仓库。项目可以关联多个目录，也可以只有资料和任务。

项目资料与可见历史由 Relay 保存。更换执行 Agent 或主 Agent 后仍可使用这些材料。Agent 内部上下文窗口、隐藏状态和运行时缓存不作为项目资料的唯一存储。

参考文章采用项目协调者、执行线程、共享记忆与资料库来组织长期工作。Relay 借鉴这些产品结构；本地多 Agent 的连接和调度由自身实现。[Claude Projects redesigned](https://claude.com/blog/projects-redesigned)

## 4. 主 Agent 与执行 Agent

主 Agent 是项目中的角色，可绑定到具备所需能力的 ACP Agent。执行 Agent 可以与主 Agent 使用同一运行时，也可以来自不同运行时。

一次工作过程：

1. 用户在项目主对话或桌面入口提出需求。
2. Relay 保存本次输入及来源，将相关项目材料交给主 Agent。
3. 主 Agent 决定直接处理、延续已有任务，或创建执行线程。
4. 委派时指定目标、负责 Agent、需要的项目材料和预期产物。
5. Relay 建立相应 ACP 会话，执行派发、记录状态并回传结果。
6. 主 Agent 审阅结果，必要时补充任务，向用户汇报并整理项目记忆。

任务拆分和语义判断属于主 Agent；进程启动、队列、并发限制、状态记录和恢复属于 Relay。

用户可以展开执行线程查看或补充要求。线程级调整同步到主 Agent 可见的任务记录，保持整体工作方向一致。

## 5. 桌面交互

### 划词工具条

参考用户提供的紧凑横向工具条。建议显示：Relay、当前项目、解释、摘要、翻译、加入项目、输入框和展开按钮。

- 支持的网页中，选区稳定后在附近显示，可切换为快捷键触发。
- 显示目标项目，用户可切换；同一项目中由主 Agent 接收请求并决定如何处理。
- “加入项目”只保存资料；“解释”等动作保存本次材料并提交具体需求。
- 工具条出现时保持原选区，用户点击输入框后再获取键盘焦点。
- 回复在小窗流式显示，可以追问或展开到项目主对话。
- 无法获取选区时提供手动粘贴入口，不复用上一次选区。

### 快捷面板

全局快捷键唤起输入框，展示当前项目和可移除的上下文卡片。窗口、文件和选区来源清晰可见。

未选择项目时，建议进入“收件箱”项目，方便即时使用和后续归档。该默认行为为产品建议。

### 项目主窗口

工作台参考图采用三栏布局。当前界面按最新要求先保留左侧导航与中间项目工作区，暂时移除右侧运行中任务、近期结果与上下文栏。整体采用浅色、留白充分的 macOS 桌面风格。

左侧包含 Home、Inbox、Projects、Agents 与 Settings；中间包含项目标题、欢迎区、多行输入框、上下文入口与快捷动作。资料库、记忆、决策与成果后续逐项接入。

先实现可运行的界面壳子，验证布局、项目切换和输入交互，再逐步连接真实数据与 Agent。壳子阶段的示例任务不能被表述为真实执行结果；Agent 接入状态应明确可见。

Agent 连接配置作为独立管理入口；用户日常围绕项目与任务工作。项目设置中可更换主 Agent、指定可用执行 Agent。

### 当前 Codex 接入流程

1. 用户在输入框中打开 Harness + Model 菜单，Codex 作为内置入口展示。
2. 首次连接由 Relay 下载并校验固定的组件版本，无需预先安装 Codex 或 Node。
3. 可复用已有 Codex 登录；未登录时显示 Agent 返回的认证入口。
4. 会话建立后显示真实模型及配置；切换经 Agent 确认后生效。
5. 用户发送消息，查看流式回复和工具状态，需要时批准或拒绝执行，并可停止当前轮次。
6. 项目保存可见历史；重启后重新连接时优先恢复原生会话，无法恢复则使用 Relay 保存的近期历史。

“Agents” 页面提供可选的本地路径选择与常见路径扫描。扫描不是首次使用的前置步骤。当前版本没有自定义供应商/密钥编辑器，API Key 认证使用启动环境或已有 Codex 登录配置；ChatGPT 可通过浏览器登录。

### 语音与视觉

语音输入进入当前项目与线程，支持可见转写、回复朗读和打断。视觉输入可为一次性选区截图，也可为主动开启的窗口共享。

截图附带采集时间；用户说“这里”时使用本轮关联的画面。语音唤醒和持续共享显示明确状态并可随时结束。

## 6. 上下文连续性

- **项目持久，执行会话可替换。** 删除或重建某个 Agent 连接不会删除项目资料。
- **共享资料，按任务取用。** 主 Agent 委派相关上下文，执行 Agent 不必接收项目全部历史。
- **跨入口保持归属。** 小窗、主窗口、语音输入都记录项目和线程标识。
- **资料保存与长期记忆分开。** 原始材料可归档，事实与决策带来源和版本；执行结果经主 Agent 整理后进入共享记忆。
- **新材料不强行打开新线程。** 默认交给当前项目主 Agent，由其判断延续或拆分。
- **角色切换可交接。** 更换主 Agent 时提供项目目标、记忆、待办、运行中任务和结果；更换执行 Agent 时重建相应执行上下文。
- **外部材料作为引用。** 网页、文件和 OCR 内容不会被提升为项目指令或运行权限。

项目上下文长期保存不意味着每次请求都发送全部资料。界面应能说明当前任务使用了哪些材料。

当前版本支持创建和编辑项目，维护项目指令及手动粘贴的文字资料。资料按用户选择参与上下文，修改在下一轮同步。已有会话只追加变化，未变化的资料不重复发送；语言切换不改项目内容。回复详情可查看交付方式、首次文字延迟和上游返回的缓存读取用量。项目资料的保存与服务端缓存有效期无关，不能将“已同步”当作“缓存命中”。

## 7. 首版建议范围

首版应验证三个闭环：

1. **项目闭环**：创建项目 → 加入材料 → 与主 Agent 对话 → 重启后恢复项目记录。
2. **桌面闭环**：网页划词 → 选择项目 → 点击动作 → 小窗回复 → 展开到同一项目。
3. **委派闭环**：主 Agent 创建任务 → 通过 ACP 调用执行 Agent → 返回产物 → 主 Agent 整理结果与项目记忆。

先验证单主 Agent 和单执行 Agent 的委派，再扩展并行任务和更多运行时。语音按键输入、朗读、截图问答可以随后接入；唤醒词和持续视觉模式逐步完善。

首版 UI、运行管理和数据模型应包含项目与委派，避免将它们推迟到客户端已有大量独立会话之后再补建。

## 8. 验收重点

| 场景 | 通过条件 |
| --- | --- |
| 项目持久化 | 重启客户端或重建 Agent 会话后，项目资料、决策和成果仍可查看 |
| 上下文分离 | 同一项目可更换执行 Agent，并使用明确选取的已有材料 |
| 主 Agent 调度 | 委派由主 Agent 发起，子任务状态与结果能回到主对话 |
| 角色更换 | 更换主 Agent 后识别已有任务，避免重复派发仍在执行的工作 |
| ACP 连接 | 在声明支持的协议版本上完成握手、对话、更新与取消 |
| 网页选区 | 支持的页面可出现工具条，内容和目标项目准确 |
| 小窗展开 | 展开后保持相同项目、线程和任务状态 |
| 取消任务 | 显示取消中，处理返回的最终状态，不将取消伪装为完成 |
| 材料追溯 | 可查看任务引用的材料以及记忆结论的来源 |
