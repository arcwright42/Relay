# Relay 产品规格

需求更新：2026-10-04。此版采用持续主对话、按需委派任务和原生记忆，取代以 Project 为必经容器以及 Jev prompt 归属判断。首个可用 Harness 为本地 Codex。

## 产品定位

Relay 是面向个人用户的原生桌面 Agent 入口。用户一直与 Relay 沟通，Relay 记住有来源的偏好、决定与工作线索，并按需要启动和跟进独立任务。UI 和核心使用 Rust，采用 GPUI + GPUI Kit，macOS 优先。

“本地”指应用、数据及 Harness 运行位置；模型推理与 ASR/TTS 是否联网取决于所选服务。Relay 连接本地已有安装，不管理 Harness 本体的安装升级。

## 主对话、任务与记忆

| 概念 | 用户行为与实现 |
| --- | --- |
| 主对话 | 首页、全局快捷入口、语音默认进入同一个 Relay thread；改变话题不会创建新会话 |
| 任务 thread | 主 Agent 为独立执行工作创建，侧栏与活动页可打开查看、追问和处理授权 |
| ACP session | thread 下可恢复或替换的执行上下文，不能作为长期身份 |
| 记忆 | 有来源和版本的 observation、偏好、事实、决定、摘要和工作状态 |
| 主题集合 | 从历史资料与记忆派生的多对多集合，可跨 session，不决定消息去向 |
| 个人文件 | 所有任务共享的成果与文件目录，不按 thread 划分 |

用户从任务详情或显式任务选择进入时，输入属于该任务。其他输入进入主对话。Agent 可以基于上下文调用 `continue_task`，也可以创建独立任务；不确定“继续哪个”时澄清，不能仅凭主题接近自动改投。一个主对话轮次可以协调多个任务。

主 Agent 通过原生工具读取任务、委派工作、记录交接、检索和维护记忆。后台 observer 只提炼候选，不把助手建议直接视为用户决定。来源改写使派生记忆失效，修订有替代关系，遗忘可撤下来源及其派生记忆。用户通过对话控制提炼开关和预算、查看记忆来源、合并主题。

## 用户入口

- 主窗口以 Relay 对话为首页；侧栏展示任务与历史 thread，活动页展示实际任务状态。
- `⌃⌥Space` 取得当前选区与可用 URL，默认交给 Relay；可明确选择任务。抓取未完成不阻塞发送，迟到网页正文不改写已发送内容。
- 小窗与工作台共享目标 thread 的消息和连接，各窗口保留自己的未发送草稿。展开保持目标；不会因快捷面板另建项目。
- 语音唤醒默认关闭。开启后说“嘿 relay / Hey Relay”，或在设置中开始语音会话。处理和播放阶段暂停收音，结束后继续听；Esc 或结束按钮回到等待唤醒，关闭开关或退出应用释放麦克风。

无法取得选区时允许直接输入；不使用旧内容填补缺失。系统权限、认证和工具授权均展示实际状态。授权在目标任务或主对话处理，后台记忆提炼不弹出任意工具授权。

## 资料、产物与上下文

thread 保留目标、指令和选用文字资料。资料单条上限 12,000 字符，最多 64 条，选用资料和指令合计最多 32,000 字符；修改在下一条消息生效，不改变在途轮次。资料编辑不是记忆确认操作。

任务成果保存到统一个人文件空间，文件 Tab 自动发现。文本编辑有外部修改检测，冲突时保留草稿、支持另存副本。对话的本地文件链接可以跳到文件预览。具体设计见 [个人文件工作区](PERSONAL-FILES.md)。

每轮追加必要的角色、有限任务状态和相关记忆索引。完整历史、详细记忆和来源按需检索，主 Agent 对证据进行取舍，不把全部历史一次送给模型。持久记忆独立于 Harness，上下文缓存由 Harness/模型控制，不承诺跨模型共享缓存。

## 一致性与用户控制

任务创建先返回持久 ID，排队不表示执行完成。正在执行的任务需要权限时标记等待；执行结束先进入待检查，由主 Agent 审阅后才标记完成。进程退出时未知投递标记中断，重启后不自动重做可能有副作用的操作。

后台提炼默认启用、最多 60 次模型调用/小时，实时事件优先。主对话连接后才开始推理，用户可通过对话暂停或调整额度，原始资料仍可搜索。每条候选有来源；确认和修订由主 Agent 使用版本化工具提交。

主题归类用于找回相关会话，可以一会话多主题、多会话共享主题。原生 session 的可见历史仍按原身份保存，导入不接管外部 Client。删除派生记忆或遗忘某个来源不会删除用户原始聊天档案；该范围需要在对话中说明。

## 迁移、验收与后续

旧 Project 变为历史 thread，原始目录和会话文件保留。新的主对话固定独立身份；旧薄记忆作为历史来源重新提炼。旧 Jev 配置不再使用，无需新的路由服务或密钥。

验收包括跨话题保持主对话、显式任务继续、异步结果回收、授权和取消的轮次关联、重启不重复执行、历史长文本完整索引、来源修订失效、跨 session 主题集合以及 MCP 在 ACP 新建/恢复时可用。详细技术边界与测试见 [原生机制](NATIVE-MEMORY.md)。

后续工作包括更多 Harness、外部原生 session 续聊、向量检索与聚类质量评测、记忆/主题可视化、跨设备备份、截图及持续视觉。当前不以这些能力作为已实现功能对外呈现。
