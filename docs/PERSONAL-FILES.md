# 个人文件工作区

需求基线：2026-10-02。面向个人用户，提供独立 **文件 / Files** Tab。文件保存在本地统一的个人目录，不按项目划分；本次不包含多人协作、成员权限、分享、云端同步或协同编辑。

## 用户操作

- 左侧点击 **文件**，直接进入个人文件列表，无需创建或选择项目。
- 在完整列表中浏览文件夹，使用面包屑和文件名搜索定位文件。点击文件进入预览或编辑，返回列表后仍保留草稿。
- 顶部支持导入多个文件、新建文本文件和新建文件夹。同名文件保留原样，使用新名称导入或创建。
- 文本及 Markdown 支持预览、编辑、**保存 / ⌘S** 和保存副本。Markdown 预览直接显示当前编辑内容。
- 图片直接在 Relay 内展示。PDF 与 Office 文档在 Quick Look 可用时展示首页缩略图；点击 **用系统应用打开** 查看完整文档。HTML、SVG 和代码以文本查看与编辑。
- 各会话的 Agent 默认使用同一个个人文件目录，成果进入同一份列表。文件 Tab 显示期间每两秒后台检查目录和当前文件；再次进入时立即刷新。
- 对话回复和 Markdown 文件内的本地链接可打开对应文件。支持相对路径、个人目录内的绝对路径、`file://`、URL 编码和代码链接的行号。网页链接继续用浏览器打开。

已保存的文件随个人目录保留，不依赖 ACP 会话。切换文件或其他导航时，未保存的编辑保留在当前工作台窗口；关闭窗口或退出后，需要重新打开已保存版本。

## 文件与 Agent 的关系

默认目录为 `~/Library/Application Support/Relay/files`，遵循 `RELAY_DATA_DIR`。文件服务独立于项目和 Agent 的工作目录配置。各会话默认使用同一目录；手动选择其他工作目录时，Agent 接收个人目录的绝对路径，并默认将交付文件保存在个人空间。

旧的 Relay 管理目录 `projects/<id>/workspace` 中已有文件会复制到个人目录，合并同名文件夹，对内容不同的同名文件添加数字后缀。原文件保留，迁入只执行一次；用户指定的外部目录不移动。

Agent 可以直接读取和写入这些普通文件，并返回可点击的 Markdown 绝对路径。个人目录路径是稳定的上下文配置，只在快照或改变时交付；文件内容不自动拼入每轮上下文。用户明确指定其他保存位置时遵循用户指令。外部工具写到其他目录的文件可导入个人空间。

## 界面

参照本机 Space 的静态列表组件与 CSS：文件名用 16px，操作和次级信息用 14px，间距以 4px 为单位。主界面使用完整文件列表和统一工具栏，打开文件进入整页预览或编辑；文件页不展示项目选择、操作教程或固定的空白预览栏。全局字体、侧栏行高和细小文案同时调整为可读尺寸。

## 编辑与保存

打开可编辑文件时保存内容 SHA-256；写入在后台完成，准备好临时文件后再次检查原内容，再原子替换。Agent 或其他程序造成已检测到的内容变更时，保存返回冲突，不替换原文件。

干净的预览跟随外部更新；有未保存修改的编辑保留正文并提示冲突。用户可载入磁盘最新版本并舍弃当前编辑，或将当前编辑保存为新文件。读取、保存或导入失败不清空编辑内容。

每个编辑位置包含打开时的个人目录和相对路径。Agent 工作目录切换不改变个人文件位置；伪造或过期的位置不能把保存重定向到其他目录。目录切换和快速选择文件都有请求版本检查，过期后台读取不会覆盖新的选择。

可编辑文本最多 2 MiB，图片预览最多 20 MiB；非 UTF-8、二进制和更大的文本通过系统应用查看。文件列表一次显示当前目录最多 5,000 个条目。个人目录之外的路径、符号链接和目录穿越不会通过文件服务读取或写入。

`cargo run -p relay-ui --example quick_preview --locked -- /tmp/relay-files-preview --workspace` 使用真实 GPUI / Metal 渲染，生成普通和窄窗口下的文件列表、Markdown、编辑及图片场景，不需要操作桌面窗口或连接真实 Agent。
