# 本地 Client 会话与原生记忆

Relay 使用用户本地安装的 Harness。后台归档服务的同步对象是本地 Client 的原生会话，包含用户在 CLI、桌面 Client 等入口发起的对话。首版接入 Codex；Claude Code、OpenCode 的解析器后续按同一服务边界扩展。

## 记忆入口

左侧入口为 **记忆**。原来的“本地会话”独立 Tab、手动归属、按任务筛选及工作目录自动匹配已移除。原生会话 ID 只标识原始会话，不决定任务身份或输入目标。

记忆页面提供三种视图：

- **记忆**：分页查看候选与已确认记录，按正文或标题进行字面搜索；可查看证据、确认、修订、遗忘。
- **主题**：展示已生成的主题标签、记忆数和来源会话数，点击后筛选关联记忆及来源。这是标签集合，不是向量聚类。
- **来源片段**：查看已经入库的材料及提炼状态。来源全文按页展开，外部会话还可跳到只读原始归档；归档每页 40 条消息，长消息显示 12,000 字预览并支持复制全文。

页面直接读取原生数据库中的待提炼、进行中、已处理、失败、候选、确认数量。导入成功不表示已完成提炼；处理完成也可能没有生成值得保存的记忆。零记忆和零主题显示真实空状态。

归档完成后由原生记忆 worker 增量读取：按消息分组和大小拆分来源片段、建立全文索引，再通过独立 observer 提炼候选与主题。用户可在页面暂停后续提炼、重试失败项、同步来源。主对话未连接、额度用尽或 observer 连接失败会显示相应状态。暂停后正在执行的任务可以继续完成。

确认与修订创建带原来源版本的新记录，旧记录标为被替代；来源已变化时拒绝提交。遗忘单条记忆撤下该记忆；遗忘来源片段会撤下其派生记录并阻止该片段重导入。两者均不删除原始会话文件，操作前展示具体范围。详见 [原生记忆](NATIVE-MEMORY.md)。

## 快照与增量

启动时同步一次，每次同步结束后等待 **30 分钟**，也可在记忆页面点击“同步来源”。该间隔只控制本地会话归档；任务资料与记忆仍随下一条 ACP 消息交付。

Codex 来源为 `$CODEX_HOME/sessions` 和 `$CODEX_HOME/archived_sessions`，未设置时使用 `~/.codex`。读取 JSONL 的 `session_meta` 与 `response_item` 中的可见用户/助手文字，忽略开发者指令、推理、工具输出、重复事件和已知环境注入项。不连接或接管用户已经运行的对话。

每个会话保存自己的归档、最后完整记录的字节位置及已提交前缀的 SHA-256。文件长度、修改时间和文件身份均未变化时跳过；变化时校验已提交前缀，追加只解析新增完整行，截短或改写则重新建立当前快照。校验变更文件的旧前缀仍需读取旧字节，不重复解析、生成摘要或调用模型。未写完的尾行不推进游标。

原生会话 ID 用于去重，移动到 archived_sessions 后保持同一会话身份。原始文件只读。损坏的完整记录不推进快照；读取失败时保留已有归档。源文件消失后保留已导入的记录并显示来源不可用。未知版本或损坏的 Relay 归档、目录不会被覆盖。

单条 JSONL 记录读取上限为 64 MB，超出时保留已有快照并提示同步失败；压缩上下文等非对话记录不会写入归档。Relay 归档被删除而来源仍在时，下次同步可重新建立快照。

## 存储与边界

```text
Relay/
  client-sessions/index.json       # 会话目录、来源文件状态、同步时间
  client-sessions/archives/<hash>.json  # 完整可见文字及同步游标
  relay.sqlite3                   # 来源版本、提炼队列、记忆、主题和任务
```

归档与目录采用 0600 文件权限及原子替换。目录只保存元数据；打开会话时在后台加载文字。导入本身不执行模型请求、不修改原生记录；后台记忆提炼单独遵循开关和每小时预算。完成提炼前也可使用原文索引。

外部 session 仍是只读导入，尚不支持接管原生运行中会话或原生续聊。Relay 内部独立任务已经实现，使用新的 ACP session；内部 session 和 observer 输出不重复当作外部记忆来源。
